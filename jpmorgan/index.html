Featured Project

Real-Time Stock Market Streaming Platform

Python Kafka Spark PostgreSQL Redis Docker

Built this to understand how real trading systems work—specifically, how to process 1,000+ stock price updates per second without dropping data or showing stale information. The system uses Kafka for message queuing with 3 partitions for parallel processing, Spark Structured Streaming with exactly-once semantics and PostgreSQL with optimized composite indexes for time-series queries.

Key Achievement: Added Redis caching layer that reduced database load by 60%, enabling sub-30 second latency for real-time market analytics. Containerized with Docker for production-ready deployment with self-healing capabilities.

This project taught me that building resilient systems isn't about preventing failures - it's about designing systems that gracefully handle inevitable failures. Services can crash and restart and the system just keeps running. Hit 99.9% uptime during testing, which I know is critical for anything running in a bank's infrastructure.
